The Seven Real-World Features

Designed strictly around the daily pain points of site engineers, quantity surveyors, and project managers.

FEATURE 01
📑

Project Document Q&A

Instantly interrogate complex structural drawings, architectural plans, tender BOQs, bar bending schedules (BBS), and daily logs. Delivers concise answers backed by clickable drawing citations.

Evidence Grounding: Vector + BM25 Lexical + Reciprocal Rank Fusion (RRF).
FEATURE 02
🧮

Deterministic Quantity Engine

Automates construction quantity takeoffs: rebar weight (IS 1786), wet/dry concrete mix volumes, shuttering contact area, earthwork excavation, and brickwork count using pure code formulas.

Safety Rule: Pure Python arithmetic modules with full unit & range validation.
FEATURE 03
⚖️

BOQ ↔ Drawing Cross-Check

Cross-references tender BOQ bill items against quantities extracted directly from approved drawings. Identifies budget under-measurements and flags variances without ungrounded error accusations.

Output: Exact delta in absolute and percentage terms (+14.8% variance alerts).
FEATURE 04
🔍

Element & Schedule Lookup

Single-query lookup for any structural element (e.g. Column C-12, Footing F-4, Beam B-104). Instantly pulls dimensions, schedule tables, bar diameters, cover, and stirrup spacing into one consolidated view.

Speed: Replaces 20-minute manual drawing searches with instant 2-second lookups.
FEATURE 05
⚠️

Revision & Conflict Intelligence

Detects conflicting specifications across project documents (e.g. Structural drawing specifies T8 @ 150mm ties while the BBS specifies T8 @ 200mm). Prevents costly on-site bar bending mistakes.

Resolution: Flags clash evidence and prompts verification rather than guessing.
FEATURE 06
📋

DPR & Site Progress Assistant

Converts raw voice notes, WhatsApp text messages, and concrete plant delivery tickets into structured Daily Progress Reports. Tracks daily pour volumes, manpower headcount, and delay causes.

Workflow: Generates auditable daily logs and automated weekly contractor summaries.
FEATURE 07
🛡️

Site Issue & RFI Assistant

When a site clash or discrepancy is discovered (such as MEP ducts colliding with structural downstand beams), the system automatically drafts a formal, traceable Request for Information (RFI).

Integrity: Compiles coordinates and drawing snapshots for consultant review.
